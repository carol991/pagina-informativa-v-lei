# Mundo do Vôlei: História, Regras e Evolução

## 📝 Descrição do Projeto
Este projeto consiste em uma página informativa em formato de artigo digital desenvolvida para apresentar a história, as regras básicas e a importância do trabalho em equipe no voleibol. A página possui um design limpo, responsivo e estruturado de forma semântica.

## 🎯 Tema Escolhido
*   **Tema:** Esportes (Voleibol e sua evolução histórica)

## 🛠️ Tecnologias Utilizadas
*   **HTML5** para estruturação semântica do conteúdo.
*   **CSS3** (Flexbox, Media Queries e Efeitos Dinâmicos) para estilização e responsividade.
